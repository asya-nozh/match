# Match — платформа для знакомств по интересам

Дипломный учебный проект веб-приложения для поиска друзей, общения и совместного досуга. Пользователи заполняют профиль, находят людей с похожими интересами, выражают симпатию и общаются после взаимного отклика.

## О проекте

МЭТЧ объединяет поиск собеседников и выбор мест для встреч. Интерфейс включает публичную часть, личный кабинет участника и отдельные разделы для модератора и администратора.

## Основные разделы

- Главная страница, справка, обратная связь и правовая информация.
- Регистрация с подтверждением электронной почты и вход.
- Профиль: фотография, город, цели общения и интересы.
- Лента анкет, фильтры, симпатии и взаимные связи.
- Чаты с обновлением сообщений.
- Места для встреч.
- Жалобы, блокировки и обращения к модерации.
- Панели администратора и модератора, статистика и управление местами.

## Технологии

- HTML5, CSS3, JavaScript.
- PHP 8.2+, MySQL 8.4; локально также проверено с MariaDB 10.4.
- MySQLi, сессии, CSRF-токены и хеширование паролей.
- SMTP для подтверждения почты.
- Необязательная интеграция OpenRouter для обработки интересов; без ключа используется локальный словарь.

## Что реализовано

- Вёрстка публичных страниц и интерфейсов личного кабинета.
- Серверная авторизация и разграничение доступа по ролям.
- Хранение профилей, интересов, связей, переписки и мест в реляционной базе.
- Обработка действий пользователя через PHP и JavaScript.
- Интерфейсы модерации и администрирования.

## Быстрый запуск с Docker

Требуется установленный Docker с Docker Compose.

1. Скачайте проект и откройте терминал в его папке.
2. Скопируйте `.env.example` в `.env`. Задайте собственные `DB_PASSWORD` и `MYSQL_ROOT_PASSWORD`. Для Docker оставьте `DB_HOST=db` и `DB_PORT=3306`.
3. Выполните `docker compose up --build -d`. При первом запуске база создаётся автоматически из `sql/schema.sql`.
4. Для наполнения **пустой** базы выполните `docker compose exec web php scripts/seed-demo.php`. Команда выведет логины и случайный пароль. Скрипт не запускается через сайт и не изменяет непустую базу.
5. Откройте [Match на компьютере](http://localhost:8080).

Демо-логины: `demo_user`, `demo_anna`, `demo_liza`, `demo_admin`, `demo_moderator`. Пароль выводится только при наполнении базы. Это тестовые аккаунты, а не реальные пользователи. Не используйте их в публичном рабочем сервисе.

Остановка: `docker compose down`. База остаётся в Docker volume. Изменение SQL-файла не обновляет уже созданную базу автоматически.

## Запуск в Open Server / XAMPP

1. Включите PHP 8.2+ с расширениями `mysqli`, `mbstring`, `openssl` и сервер MySQL/MariaDB.
2. Создайте пустую базу `match_project` с кодировкой `utf8mb4`, импортируйте `sql/schema.sql` через phpMyAdmin.
3. Настройте переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` для PHP. Без них локальные значения: `127.0.0.1:3306`, база `match_project`, пользователь `root`, пустой пароль. Такие значения предназначены только для локальной разработки.
4. Наполните базу командой `php scripts/seed-demo.php`, используя те же настройки подключения.
5. Откройте папку проекта через локальный веб-сервер, например `php -S 127.0.0.1:8080`.

## Электронная почта

Вход в демонстрационные аккаунты работает без почтового сервера. Для регистрации новых пользователей и доставки кодов подтверждения настройте `MAIL_SMTP_HOST`, `MAIL_SMTP_PORT` (обычно 465, подключение SSL), `MAIL_SMTP_USERNAME`, `MAIL_SMTP_PASSWORD`, `MAIL_FROM_EMAIL`. Без SMTP регистрация с подтверждением почты не завершится. Реальные пароли в репозитории отсутствуют.
